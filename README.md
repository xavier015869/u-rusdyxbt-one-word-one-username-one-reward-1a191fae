## About

Entry for the make.fun bounty [One Word, One Username, One Reward](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae).

The program in `main.ts` does one thing: it writes the entrant's own make.fun
username — a single word, with no explanation and no trailing newline — to
`/output/entry.txt`, exactly as the bounty requires. The handle is assembled
in the source from its name stem and numeric suffix so it is plain to see
that the word is the entrant's real registered username.

## Run

```sh
node main.ts
```

This creates `/output/entry.txt` containing the single-word entry.
